# Python For Financial Markets

A quantitative finance toolkit applying Python to real market data — covering equity research, portfolio optimization, predictive modeling, trading strategies, and NLP-based market intelligence.

Built as a practical bridge between financial theory and market implementation, using data sourced live from Yahoo Finance, NSE/BSE, and other financial APIs.

## Tech Stack

- **Data:** Yahoo Finance (`yfinance`), NSE/BSE APIs
- **Analysis:** `pandas`, `numpy`, `scipy`
- **Machine Learning:** `scikit-learn`, `TensorFlow/Keras`, `Facebook Prophet`
- **Technical Analysis:** `TA-Lib`, `pandas-ta`
- **Portfolio Optimization:** `Riskfolio-Lib`, `vectorbt`
- **NLP:** `NLTK`, `TextBlob`, `VADER`
- **Visualization:** `matplotlib`, `plotly`, `seaborn`

## Getting Started

```bash
# Clone the repository
git clone https://github.com/aman38649/Python-For-Financial-Markets.git
cd Python-For-Financial-Markets

# Install dependencies
pip install yfinance pandas numpy scikit-learn matplotlib plotly seaborn
pip install pandas-ta riskfolio-lib vectorbt prophet

# Launch Jupyter
jupyter notebook
```
